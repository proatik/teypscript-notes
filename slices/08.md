## 8. Utility Types

TypeScript ships a set of **global utility types** — no imports needed. They transform existing types to produce new ones.

### ✅ `Partial<T>` & `Required<T>`

#### `Partial<T>`

Makes all properties of `T` **optional**.

```ts
interface User {
  name: string;
  age: number;
  email: string;
}

type PartialUser = Partial<User>;
// { name?: string; age?: number; email?: string }

function updateUser(user: User, patch: Partial<User>): User {
  return { ...user, ...patch };
}

updateUser(user, { name: "Atik" }); // only name is required
```

#### `Required<T>`

Makes all properties of `T` **required** (removes `?`).

```ts
interface Config {
  port?: number;
  host?: string;
}

type StrictConfig = Required<Config>;
// { port: number; host: string }
```


### ✅ `Pick<T, K>` & `Omit<T, K>`

#### `Pick<T, K>`

Creates a type with only the specified keys from `T`.

```ts
interface User {
  id: number;
  name: string;
  email: string;
  password: string;
}

type PublicUser = Pick<User, "id" | "name" | "email">;
// { id: number; name: string; email: string }
```

#### `Omit<T, K>`

Creates a type with all keys from `T` **except** the specified ones.

```ts
type SafeUser = Omit<User, "password">;
// { id: number; name: string; email: string }
```

`Pick` and `Omit` are inverses — use whichever requires listing fewer keys.


### ✅ `Record<K, V>`

Creates an object type with keys of type `K` and values of type `V`.

```ts
type Role = "admin" | "user" | "guest";

const permissions: Record<Role, string[]> = {
  admin:  ["read", "write", "delete"],
  user:   ["read", "write"],
  guest:  ["read"],
};
```

`Record<string, unknown>` is the type-safe alternative to `{ [key: string]: any }`.

```ts
function toRecord<K extends string, V>(
  keys: K[],
  getValue: (key: K) => V
): Record<K, V> {
  return Object.fromEntries(keys.map(k => [k, getValue(k)])) as Record<K, V>;
}
```


### ✅ `Readonly<T>`

Makes all properties of `T` **read-only** — prevents reassignment.

```ts
interface Config {
  port: number;
  host: string;
}

const config: Readonly<Config> = { port: 3000, host: "localhost" };

config.port = 8080; // Error — cannot assign to 'port' because it is a read-only property
```

Note: `Readonly` is shallow — nested objects are still mutable. Use a recursive `DeepReadonly` for deep immutability.


### ✅ `ReturnType<T>` & `Parameters<T>`

#### `ReturnType<T>`

Extracts the return type of a function type.

```ts
function getUser() {
  return { name: "Atik", age: 30 };
}

type User = ReturnType<typeof getUser>;
// { name: string; age: number }
```

#### `Parameters<T>`

Extracts the parameter types as a tuple.

```ts
function createUser(name: string, age: number, admin: boolean) {}

type CreateUserArgs = Parameters<typeof createUser>;
// [name: string, age: number, admin: boolean]

// Useful for forwarding arguments
function wrapper(...args: Parameters<typeof createUser>) {
  return createUser(...args);
}
```


### ✅ `Awaited<T>` (TS 4.5+)

Recursively unwraps a `Promise` type — models what `await` produces.

```ts
type A = Awaited<Promise<string>>;           // string
type B = Awaited<Promise<Promise<number>>>;  // number
type C = Awaited<string>;                    // string (non-promise passes through)
```

```ts
async function fetchUser(): Promise<User> { /* ... */ }

type FetchedUser = Awaited<ReturnType<typeof fetchUser>>;
// User — not Promise<User>
```


### ✅ `NonNullable<T>`

Removes `null` and `undefined` from a type.

```ts
type A = NonNullable<string | null | undefined>; // string
type B = NonNullable<number | null>;             // number
```

```ts
function process<T>(value: T): NonNullable<T> {
  if (value == null) throw new Error("Value is null or undefined");
  return value as NonNullable<T>;
}
```


### ✅ `Exclude<T, U>` & `Extract<T, U>`

#### `Exclude<T, U>`

Removes types from union `T` that are **assignable to** `U`.

```ts
type A = Exclude<string | number | boolean, boolean>;
// string | number

type B = Exclude<"a" | "b" | "c", "a" | "c">;
// "b"
```

#### `Extract<T, U>`

Keeps only types from union `T` that are **assignable to** `U` — the opposite of `Exclude`.

```ts
type A = Extract<string | number | boolean, boolean>;
// boolean

type B = Extract<"a" | "b" | "c", "a" | "c">;
// "a" | "c"
```

#### `Exclude` vs `Omit`

| | `Exclude` | `Omit` |
|---|---|---|
| Operates on | Union types | Object types |
| Removes | Type members from union | Keys from object |
| Example | `Exclude<A \| B, B>` → `A` | `Omit<{ a, b }, "b">` → `{ a }` |


### ✅ `NoInfer<T>` (TS 5.4+)

Prevents TypeScript from using a type parameter as an inference site. Useful when you want one argument to drive inference and another to be checked against it.

```ts
// Without NoInfer — defaultColor incorrectly widens inference
function createLight<C extends string>(colors: C[], defaultColor?: C) {}

createLight(["red", "yellow", "green"], "blue"); // no error — "blue" widens C

// With NoInfer — defaultColor must match what was inferred from colors
function createLight<C extends string>(colors: C[], defaultColor?: NoInfer<C>) {}

createLight(["red", "yellow", "green"], "blue");  // Error — "blue" not in union
createLight(["red", "yellow", "green"], "red");   // ok
```


### ✅ Quick Reference Table

| Utility Type | What it does |
|---|---|
| `Partial<T>` | All properties optional |
| `Required<T>` | All properties required |
| `Readonly<T>` | All properties readonly |
| `Pick<T, K>` | Keep only keys `K` |
| `Omit<T, K>` | Remove keys `K` |
| `Record<K, V>` | Object with keys `K` and values `V` |
| `Exclude<T, U>` | Remove `U` from union `T` |
| `Extract<T, U>` | Keep only `U` from union `T` |
| `NonNullable<T>` | Remove `null` and `undefined` |
| `ReturnType<T>` | Return type of function `T` |
| `Parameters<T>` | Parameter types of function `T` |
| `Awaited<T>` | Unwrap `Promise<T>` recursively |
| `NoInfer<T>` | Block inference at this position (TS 5.4+) |
