## 5. Functions

### ✅ Typed Parameters & Return Types

```ts
function add(a: number, b: number): number {
  return a + b;
}

const greet = (name: string): string => `Hello, ${name}`;
```

TypeScript infers return types automatically — but annotating is recommended for public functions (acts as documentation and catches mistakes).

```ts
// Inferred return type: number
function multiply(a: number, b: number) {
  return a * b;
}

// Explicit — safer for exported / public functions
export function divide(a: number, b: number): number {
  return a / b;
}
```


### ✅ Optional & Default Parameters

#### Optional parameters — `?`

```ts
function greet(name: string, greeting?: string): string {
  return `${greeting ?? "Hello"}, ${name}`;
}

greet("Atik");           // "Hello, Atik"
greet("Atik", "Hey");    // "Hey, Atik"
```

Optional parameters are typed as `T | undefined` internally. They must come **after** required parameters.

#### Default parameters

```ts
function greet(name: string, greeting: string = "Hello"): string {
  return `${greeting}, ${name}`;
}

greet("Atik");           // "Hello, Atik"
greet("Atik", "Hey");    // "Hey, Atik"
```

Default parameters do not need `?` — TypeScript understands they're optional at the call site.


### ✅ Rest Parameters

Collect remaining arguments into a typed array.

```ts
function sum(...nums: number[]): number {
  return nums.reduce((acc, n) => acc + n, 0);
}

sum(1, 2, 3, 4); // 10
```

Rest parameters must be the **last** parameter. Can also use a tuple for mixed types:

```ts
function log(message: string, ...tags: string[]): void {
  console.log(`[${tags.join(", ")}] ${message}`);
}
```


### ✅ Function Overloads

Define multiple call signatures for a function — TypeScript picks the right one based on the arguments.

```ts
// Overload signatures (no implementation)
function format(value: string): string;
function format(value: number, decimals: number): string;

// Implementation signature — must be compatible with all overloads
function format(value: string | number, decimals?: number): string {
  if (typeof value === "string") return value.trim();
  return value.toFixed(decimals ?? 2);
}

format("  hello  ");   // "hello"
format(3.14159, 2);    // "3.14"
format(3.14159);       // Error — no matching overload
```

Rules:
- Overload signatures are listed first (most specific to least specific).
- The implementation signature is not visible to callers.
- The implementation must be compatible with all overloads.


### ✅ `void` vs `never` in Functions

#### `void`

The function runs and completes normally but returns no meaningful value (returns `undefined` implicitly).

```ts
function log(msg: string): void {
  console.log(msg);
}
```

A `void` function **can** return `undefined` — it just shouldn't return anything meaningful.

#### `never`

The function **never returns** — it either throws unconditionally or runs forever.

```ts
function fail(msg: string): never {
  throw new Error(msg); // never returns
}

function loop(): never {
  while (true) {} // never returns
}
```

`never` is also the return type of a function that has been narrowed to an impossible state:

```ts
function assertUnreachable(x: never): never {
  throw new Error("Unreachable: " + x);
}
```

| | `void` | `never` |
|---|---|---|
| Function completes | ✅ | ❌ |
| Returns `undefined` | ✅ (implicitly) | ❌ |
| Throws / infinite loop | ❌ | ✅ |
| Used for | Side-effect functions | Error throwers, exhaustive checks |


### ✅ Function Types & Signatures

#### Function type alias

```ts
type Add = (a: number, b: number) => number;

const add: Add = (a, b) => a + b;
```

#### Call signatures in object types

```ts
type Transformer = {
  label: string;
  (input: string): string; // call signature
};

const upper: Transformer = Object.assign(
  (s: string) => s.toUpperCase(),
  { label: "uppercase" }
);
```

#### Generic function types

```ts
type Identity = <T>(value: T) => T;

const identity: Identity = (val) => val;

identity("hello"); // string
identity(42);      // number
```

#### `Parameters<T>` and `ReturnType<T>`

Extract types from existing functions without redefining them:

```ts
function fetchUser(id: number, options: { cache: boolean }): Promise<User> {
  // ...
}

type FetchUserParams = Parameters<typeof fetchUser>;
// [id: number, options: { cache: boolean }]

type FetchUserReturn = ReturnType<typeof fetchUser>;
// Promise<User>
```
